# Gaia Symbolic Regression

## Project Overview

Can AI rediscover one of astrophysics' fundamental laws directly from observational data?

This project investigates whether symbolic regression can recover the relationship between stellar flux, radius, effective temperature, and distance using Gaia DR3 observations.

The recovered equation will be compared against the theoretical relation derived from the Stefan–Boltzmann Law and the inverse-square law.

## Objectives

- Obtain stellar data from Gaia DR3
- Convert Gaia photometry into apparent flux
- Perform a log-log regression baseline
- Apply symbolic regression using PySR
- Compare the recovered equation with theory
- Investigate residuals and physical causes of deviations
